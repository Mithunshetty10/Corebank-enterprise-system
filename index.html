Account Policy & State Rules

  • SavingsAccount: Enforces a strict minimum balance of $500.00 on creation and every withdrawal/transfer.
  • CurrentAccount: Allows overdrafts down to -$1,000.00 for operational liquidity.
  • PENDING State: Accounts created in PENDING cannot process deposits, withdrawals, or transfers until activated via KYC approval.
  • FROZEN State: Blocks all debit/credit transactions until unfrozen by an authorized Teller/Admin.
  • CLOSED State: Terminal state. Requires account balance to equal exactly $0.00.

Account Lifecycle State Machine (FR-07)

Teller / Admin Privileged Access

Transitions: PENDING → ACTIVE (KYC), ACTIVE ↔ FROZEN (Hold/Release), ACTIVE → CLOSED (Requires $0.00 balance).
